## Context

L 级跨模块工作。main 已积累内容、播放、骨架屏和 UI 修改；origin 是公开仓库，129 个远端 tag 均与官方同名 tag 指向相同对象。SDK 的配置值同时出现在算法自检中，不能通过修改算法来公开脱敏。

## Goals / Non-Goals

**Goals:** 统一用户可见 Playra 品牌；正式版没有日志与实验入口；关于页轻量且适配窄屏；自有版本与官方引用隔离；整理安全提交并推送。

**Non-Goals:** 不改密码算法、第三方作者署名和协议身份；不更换现有安装包 ID、Hive 路径或 MethodChannel；不删除应用数据；不声称尚未复测的真机播放已修复。

## Decisions

1. 集中品牌与发布开关。正式构建默认关闭开发工具，显式诊断构建可开启；路由与入口同时控制。
2. 关于页采用现有深色表面、淡紫强调色、少量轨道 SVG，品牌和版本为主；源代码/官方社区推广从主页面移除，许可证与致谢保留在二级入口。
3. 外部可见名称全部更新；底层 package、存储、协议标识保持兼容，不做全库类名替换。
4. 自有 tag 使用 `playra/v*`，官方 tag 从 upstream 远端拉取到本地 `upstream/*` 命名空间。清理 origin 原官方 tag 需先保存对象映射与本地备份，确认后按旧 SHA 校验删除，不重写提交。
5. 整个敏感 SDK 作为忽略的本地/CI 构建输入，提供同步及受限包导入工具。公开代码不改写或包含这些算法中的配置、自检密钥值。正式 CI 使用私有构建输入并只构建自有 tag。
6. 将已有功能修改按实现域分组提交，子模块预存删除不提交。提交前检查差异、UTF-8、构建与敏感值，推送后核对 origin/main SHA。

## Risks / Trade-offs

- 旧 tag 名被外部引用：保存 129 项映射、原提交对象和回退方法，确认后才移除旧 origin 名称。
- SDK 不能公开纳入：干净克隆必须准备本地 SDK 或 CI 私有包，构建缺失时明确失败。
- Android 原包 ID仍是兼容标识：保证当前测试安装可覆盖并保留数据，界面/系统名称均为 Playra。
- 电影真机播放仍失败：继续记录安全解析/起播错误，不标记正式播放验收完成。

## Migration Plan

先备份当前工作树与远端 tag 映射；实施入口、关于页及品牌；验证 Android/Web；整理提交、推送 main；处理确认的官方 tag 迁移并核对引用。回退只恢复本轮备份或逐项还原 tag，保留历史。
