## Why

本机 16 条动漫规则目前与后续影视来源共用未分类检索，来源列表包含无资源项，解析速度与失败恢复未参与选择。需要让真实有资源的同一作品、同一集通过稳定且快速的来源播放，并保留人工选择的优先权。

## What Changes

- 增加来源领域、接入方式、独立本地启停/分类覆盖与近期性能记录，保留旧规则 JSON。
- 播放来源按作品和有效剧集筛选，确认无结果项隐藏，异常与验证状态保留恢复入口。
- 支持自动优选、有限重试与同集备用来源，手动操作取消旧流程并保留可靠匹配的进度。
- 补齐媒体打开失败状态，支持通过配置 HTTP resolve API 接入外部算法服务，复用规则请求器及会话边界。

## Capabilities

### New Capabilities
- `classified-playback-sources`: 内容领域、可用候选、性能优选、有限恢复及 HTTP 解析适配。

### Modified Capabilities

无；延续既有唯一播放器、旧 JSON 与跨源不猜索引的要求。

## Impact

影响来源模型/服务、规则管理、来源弹层、共享播放控制器和 HTTP 服务；不修改已安装规则文件、不增加依赖、不改变作品资料与评论接口。保留之前的界面修改。
