# 安卓新版首页第一版

## 范围与验收

按 `docs/design/android-home-v1.png` 实现新版发现页的中性色明暗主题、搜索入口、推荐横幅、继续观看、番剧海报和底部导航。推荐、热门、新番读取现有 Bangumi 接口；详情、收藏、历史和恢复播放使用原有路由与仓库。生产环境仅 Android 可选择新版，默认仍为旧版。

新版布局和首页状态放在 `lib/presentation/modern/home/`，不修改旧首页、历史持久化模型或播放协议。首页搜索框打开现有完整搜索页面，避免将关键词误当成 `/search/:tag` 的标签参数。接口没有按周热门统计，筛选文案使用“热门”。历史没有持久化视频总时长，因此显示实际观看位置，不生成虚构的百分比。

验收包括真实数据加载、筛选、详情与历史入口、下拉刷新和分页、旧新样式双向切换、明暗主题、小屏与大字体布局、全部既有测试、Android debug APK 和浏览器中的独立安卓页面预览。无连接 Android 设备时，明确区分 APK 构建和真机安装结果。

## 回滚

本次修改前的文件副本及 Git 状态位于 `.dart_tool/modern-home-baseline/`，其中保留新版发现页、底部导航、导航测试与 Web 服务原始文件。回滚时逐项恢复这些副本，移除本次新增的 `modern/home/`、首页测试、独立预览入口及启动脚本；不要重置此前 Web 移植或组件库安装产生的修改。
