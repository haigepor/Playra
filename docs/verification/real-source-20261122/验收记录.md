# Playra 真实内容源与外网流验收

2026-11-22，基于 main / 9e1029f5 及此前已有页面修改。使用 LLD-AL20、Android 9，通过 ADB 操作独立测试包 `com.predidit.kazumi.playrareal`，保留原有 2.4.2 和业务数据。

## 网络与配置

手机 Wi-Fi 已开启但没有连接，系统报告无默认网络。按用户选择，测试包通过 ADB reverse 和仅监听电脑回环地址的临时 HTTP 代理访问真实外网；没有把外网流下载后替换成本地媒体。

首次构建没有内容源配置，接口返回业务码 4020；会话协商后出现 MAC 校验失败。确认项目配置使用 String.fromEnvironment，工作区没有 README 指定的配置文件，构建参数为空。随后使用用户提供的配置，通过临时私有文件传入构建。配置值没有写入源码、截图说明或本报告。

## 已修复的问题

| 问题 | 原因与修改 |
| --- | --- |
| HTTP 200 中的业务错误码没有触发会话恢复 | `callData` 在 catch 范围之外调用 `dataOf`，所以 4020 无法进入恢复分支。现把业务解析放入捕获范围，协商后只重试一次；4012/4013 也能进入既有登录失效映射。 |
| 缺少配置时错误说明不明确 | 默认客户端在网络请求前检查必需配置，返回“内容源尚未配置，请联系应用提供方”，避免发送空配置后落入加密错误。注入测试传输的路径保持可测试。 |
| 分类“最热”和“最新”报错 | 真实服务返回 400，明确要求 `latest hottest score discuss`。界面提交的是通用值 `hot/new`。在 CliCli 适配层映射为 `hottest/latest`，综合和评分保持原值。 |

生产代码改动为 `clicli_client.dart`、`clicli_config.dart`、`clicli_source.dart`；新增 `test/sources/clicli_client_test.dart` 和 `clicli_source_test.dart`。没有新增依赖、修改凭据常量或更换内容源服务器。

- 会话回归先复现失败，修复后通过。验证 HTTP 200 / 4020 协商并返回重试数据、持续过期只恢复一次、登录失效映射，以及缺少配置时的明确错误。
- 排序回归先有两个失败用例，修复后四种排序通过。最终 `flutter test --no-pub test/sources` 共 8 项通过。
- 会话与配置修改后，完整测试共 84 项通过，记录见 [tests.log](tests.log)。分类映射是其后的改动，由上述 8 项聚焦检查及真实接口、真机排序回归覆盖，没有把 88 项称为同次全量执行结果。
- 最终受影响源码和测试静态检查 0 issue，见 [analyze-final.log](analyze-final.log)。此前全量 lib/test 静态检查也通过，见 [analyze.log](analyze.log)。

## 尚有限制

真实剧集已达到首帧、换集、恢复和超过一分钟的播放进度，但多次观察到缓冲，不能称为连续流畅播放全部通过。部分封面失败，电脑直连相同地址也得到 HTTP 418 或连接重置，另有图片 404。未修改 TLS 校验或用替换图片掩盖上游失败。

手机自身 Wi-Fi/蜂窝直连仍未验证。本次结果适用于用户选择的电脑网络经 USB 转发路径和这一台手机。封面源可用性、CDN 长时稳定性、其他片目和机型没有全面验收。
