## 最新截图反馈的处理

- 首页搜索框普通字号视觉高度 40dp，点击范围至少 48dp；缩小品牌、提示文字与分类间距，保证 360dp 手机中“电视剧”完整显示；“更多”单独分隔。窄屏大字体时搜索框独占一行。
- 续播卡片收紧海报、内边距、标题和播放图标；只缩小 SDK 历史卡片的 compact 用法，个人库常规卡片尺寸保留。续播横向列表高度随文字缩放增长，并在下方保留明确间距。
- 删除空内容区的大圆角、整块灰色背景与重复边框，改为轻量图标、标题、说明和操作。正常空结果显示“暂时没有推荐内容 / 刷新内容”；真实来源错误显示“内容加载失败 / 重试”；平台不可用时提供浏览电影入口，产品提示不再暴露 Lumina 实现名称。
- 回归覆盖空结果、来源失败、点击重试后内容恢复，以及小屏、大字体和真实续播回调。
