# 新版页面样式与动效检查（2026-10-13）

## 本次范围与结果

本次按 L 级跨页面 UI 修改处理：检查页面入口和共享主题，设计与实现，测试、构建、浏览器核验，再对照修改前文件审查。服务接口、解析算法、作品编号、选集身份和播放器会话未改动。沿用 Flutter Material / shadcn_ui、深色背景和淡紫色强调色。

当前交付为 Web 预览与共用 Flutter 源码。Android 真机尚未验证本轮样式，没有重新生成 APK。

## 主要发现与处理

| 级别 | 问题和证据 | 本次处理 |
| --- | --- | --- |
| 高 | 新版主题仅覆盖部分 ColorScheme 容器，浅色/绿色种子主题仍能进入对话框；单元测试修改前复现 | 补齐深色容器、弹窗、底部弹层和输入框主题 |
| 高 | 来源检索弹窗调用全局导航，未传页面 context；用户截图和源码一致 | 检索词、别名及别名删除弹窗捕获调用页面主题，保留旧版页面自身的主题 |
| 中 | 搜索类型弹层在主题作用域外打开；下载删除确认和配色弹窗也漏传 context | 补齐主题上下文，核对其他二级页面主题包装 |
| 中 | 推荐大卡片只能固定显示一部或突然刷新 | 动漫、热门中有可用条目时、电影、电视剧、综艺、漫剧共用横向 PageView 推荐卡；最多展示 6 张，6 秒切换，420ms 过渡 |
| 中 | 自动动效容易在离屏、后台和读屏场景造成干扰 | 轮播在悬停、焦点停留、触摸、后台、隐藏 tab、路由被覆盖、离屏、减少动画或无障碍导航时暂停；按后续反馈仅显示居中指示器，移除可见页数与暂停按钮，支持点击指示器和滑动切换 |
| 中 | 推荐页双列卡封面贴边，标题和底部评分之间留白缺乏层级 | 海报内边距、独立圆角、标题/评分/详情提示分区、低对比度 SVG 线条；小于 320dp 内容宽度或字号超过 1.3 倍时改单列 |
| 中 | 播放页自动播放、手动换源纵向散落 | 合并为“智能选源”卡：状态说明、主按钮、次按钮；保留原业务回调 |
| 中 | 文本操作的 hover 继承大胶囊外形 | 统一 10dp 圆角、克制的淡紫色反馈和内边距；播放页仍保留 48dp 触摸区域 |
| 中 | 影视播放加载使用普通圆环，动漫当前集仍用静态 SVG | 复用已有 LoadingIndicator；动漫与影视共用已实现的动态播放标记，暂停或减少动画时静止 |
| 中 | 推荐骨架整块填充，和真实海报/文字结构不一致 | 双列/单列推荐骨架细分海报、标题、评分；轮播骨架与真实卡片高度对应；脉冲调整为 1800ms、较低亮度差，并隔离重绘 |
| 低 | 无数据分类连续显示多条空白提示 | 使用现有空内容 SVG 和集中说明，空列表不再显示“已显示当前全部内容” |
| 低 | 图片淡入未遵循减少动画 | 减少动画时直接呈现，普通模式 180ms 淡入 |

## 页面覆盖与 SVG 使用策略

| 页面族 | 审查方式 | 结果 |
| --- | --- | --- |
| 发现：推荐、热门、动漫、电影、电视剧、综艺、漫剧 | 源码、真实浏览器、组件测试 | 统一大推荐卡；推荐拼图单独优化。空分类不虚构推荐或榜单 |
| 日历、追番、我的 | 入口与主题源码、浏览器切换、现有组件测试 | 既有页头装饰、空状态和主要布局保留，共享主题与骨架修复自动生效 |
| 动漫播放详情 | 浏览器打开作品、选源、修改检索词；播放契约测试 | 核对标题、简介、选集、智能选源、讨论/评价入口与弹窗主题 |
| 影视播放详情 | 浏览器从轮播打开对应作品、打开选集；选集样式测试 | 深色一致、单集弹层紧凑，三个选集布局及真实编号规则保留 |
| 搜索、人物资料、图片搜索、引导、错误页 | 路由包装和既有二级页组件测试 | 已有 ModernSecondaryScope；不额外叠加与内容争抢注意力的背景 |
| 设置、历史、下载、规则、同步、关于、许可 | 路由包装、弹窗调用检查、设置组件测试 | SettingsAppearanceHost 继续覆盖这些入口，补漏下载和配色对话框 |

“覆盖”区分源码、组件测试与实际浏览器，不表示穷举每个登录态、设备原生弹窗或每一部视频。

新增 SVG：

- `assets/images/modern-feature-orbit.svg`：推荐大卡片的轨道/影片画框线条；基础 path、ellipse、rect、circle，无脚本、文字、滤镜和外链。
- `assets/images/modern-recommendation-lines.svg`：推荐拼图卡片低对比度斜线与弧线。

复用既有发现/日历/追番页头、个人页、搜索空态、无播放源等 SVG。所有装饰忽略点击并排除读屏；真实视频画面不加 SVG 装饰。
