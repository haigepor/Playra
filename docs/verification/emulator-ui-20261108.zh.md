- 该轮安装的源码指纹：`8ff9b17d7a5c582a9e6a`。APK、截图的历史 SHA256 及原生矩形证据见 [evidence.json](emulator-ui-20261108/evidence.json)；后续源码已变化。
- 隔离 Debug APK 构建、安装成功。执行的是实际 `lib/main.dart`，并非首页预览入口；生产依赖版本与项目一致。

## 未验证范围与边界

- **正式私有 Lumina profile 仍缺少匹配输入**。隔离环境沿用此前授权的匹配历史 receipt；正式 `inputs.json` 与校验未改动。因此这不是正式 release 构建恢复的证明。此前 release 的 Flutter 开发插件注册问题亦未被宣称已解决。
- **当前 SDK 流没有 Bangumi 上下文，原生弹幕入口未出现**，没有将弹幕匹配、加载或实际显示标为通过，也没有伪造业务 ID 来启用入口。
- 本轮未验证自动进入 PiP、物理传感器自动旋转、ARM 真机、其他 Android 版本，以及 Web／桌面原生发行包。模拟器窗口调整与实际全屏方向切换分别记录。
- 注入文字完成了真实搜索；没有把 ADB 硬件式输入当成软键盘弹出验收。IME、光标和键盘避让另有 Flutter 聚焦测试。
- 已将显示尺寸、密度、系统字号和旋转设置核对恢复为验证前的值。保留隔离应用安装，回到正常手机尺寸的首页，供用户继续查看。
