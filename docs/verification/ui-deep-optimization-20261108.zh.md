# 第二轮界面深查与优化

本轮延续手机端优先方向，检查公共控件、播放器控制层、播放源与选集弹层、状态提示、动效和页面装饰。保留第一轮首页、搜索、导航和日历的改动。本轮修改 13 个产品文件，没有修改播放解析、来源协议、存储或依赖。

## 发现与处理

| 位置 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 公共按钮与主题 | 全局悬停、焦点、按压底色被置为透明；按钮自身背景还会盖住 InkWell 的反馈 | 恢复轻量状态底色，将背景和边框交给 Material，移除主按钮发光阴影；保留第一轮最小 48dp 点击区 |
| 图标按钮 | 选中与禁用状态缺少显式语义 | 补充按钮、选中、禁用语义；继续使用项目已有图标库 |
| 紧凑播放器 | 时间文字与进度条挤在一行，窄屏下拖动空间不足 | 进度条独占一行，获得 44dp 高的交互区域；下行放播放/暂停、下一集、时间、全屏；时间空间不足时局部缩放 |
| 进度条读屏 | 滑杆语义合并到视频区域；拖动后依赖的读屏百分比没有随画面更新 | 为进度条建立独立语义容器，以当前播放状态更新百分比，保留前进/后退总时长 5% 的读屏操作 |
| 播放失败提示 | 消息和多个按钮横排挤压正文，切换线路藏在更多菜单 | 消息独立一行，重试和切换线路直接展示，可随宽度换行 |
| 播放源栏 | 投屏图标容易误导；固定高度限制大字体 | 改用视频资料库图标，最小高度替代固定高度，标签与来源名分配弹性空间；完整来源名保留给读屏 |
| 线路选择语义 | 实测自动线路选项与弹层标题合并为一个按钮节点 | 给线路选项增加独立语义容器 |
| 选集弹层 | 外层与内容各有一个拖动条；双倍字体下分段按钮高度不够；单线路下拉框占用大量高度 | 只保留一个拖动条，单线路省略下拉框，大字体弹层提高到最多 90% 可用高度，分段与资料目录格子随字体增高 |
| 选集状态 | 分段缺少选中态，当前分段难以辨认 | 增加分段背景和选中语义，保留原始剧集索引与排序逻辑 |
| SDK 播放详情返回 | 覆盖在封面上的返回按钮只有 36×36 | 扩大为 48×48，保留退出全屏/返回行为 |
| 视频缓冲提示 | 背景跟随浅色主题，文字固定白色 | 视频提示固定深色半透明底与白色文字/进度，避免浅色页面白底白字 |
| 动画 | 公共弹层未消费现有动画配置；播放/暂停图标和加载指示未完整响应减少动画 | 公共动画同时尊重减少动画与辅助导航；弹层使用现有时长，加载未知进度时以静态沙漏替代旋转，播放/暂停直接切换到目标状态 |
| 插画与背景 | 手机端装饰与文字更容易重叠 | 沿用现有素材，手机背景透明度降低到 8%；高对比度模式不绘制这类背景装饰 |
| 弹层定位与安全区 | 居中容器可扩大弹层空白区域，未显式启用顶部安全区 | 弹层底部对齐、按内容收缩，保留键盘避让并启用安全区 |

## 检查后保留的设计

- `PlayingMark` 已在暂停、后台、TickerMode 关闭、减少动画和辅助导航时停止动画。
- 首页轮播已有触摸、悬停、焦点、后台及减少动画控制；本轮没有增加自动滚动或额外动效。
- 海报占位图、页面插画已有不拦截点击和装饰语义隔离；继续沿用现有素材，避免新素材引入风格分裂。
- 选集保留选中/正在播放/已下载三种含义，保留线路原始索引，不用展示排序改写业务编号。

以上保留项来自源码检查，不能替代原生设备完整体验验收。
