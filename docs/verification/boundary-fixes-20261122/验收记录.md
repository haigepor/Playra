# Playra 页面边界修复验收

2026-11-22。在 main / 9e1029f5 及已有设计稿实现之上，修复深度审查确认的三项问题和暂停文案。没有提交或推送代码。

## 修复结果

| 问题 | 实现与可观察结果 |
| --- | --- |
| 搜索、分类首批结果不足一屏，后续内容不可达 | 请求完成并布局后，在仍有下一页且无法滚动时继续补页。沿用请求版本、加载中及失败约束，失败后停止自动请求。页脚增加“加载更多”，在键盘收起或视口扩大后仍可手动到达下一页。 |
| 320dp、2 倍字号下日历日期条溢出 | 按单元格可用宽度和实际字号切换单字星期标签，保持单行，不缩小系统字号。无障碍标签仍为“周一”等完整星期。 |
| 我的页面部分卡片遮挡触摸反馈 | `_settingsSurface` 改为带背景、圆角、边框和裁剪的 Material，使 ListTile 的墨水反馈绘制在卡片上。 |
| 暂停后摘要仍写“正在播放” | 摘要改为稳定的“当前 第 N 集”。播放与暂停状态继续由播放器控制按钮表达，避免摘要把当前选集误写成播放状态。 |

生产代码改动限于六个文件，原有设计稿实现和其他已有改动保留。

- `lib/pages/discover/search_page.dart`、`browse_page.dart`、`media_widgets.dart` 负责补页和手动加载入口。
- `lib/pages/calendar/calendar_page.dart` 负责星期标签适配。
- `lib/pages/profile/profile_page.dart` 负责卡片 Material 层次。
- `lib/pages/player/source_player_page.dart` 负责当前选集摘要。
