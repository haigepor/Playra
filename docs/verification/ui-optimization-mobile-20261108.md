# 手机端优先的界面优化

本轮完成公共控件、底部导航、日历入口，以及首页、搜索和 SDK 播放详情页的首轮布局调整。基线为 `57c63c29`。

## 改动

- 公共按钮最小高度 48，图标按钮最小尺寸 48×48；主按钮消费 `onPrimary`，字号与内容高度随文字增长；按钮动画遵循减少动画设置。
- 主壳层统一为底部导航和安全区保留空间。保留四个导航目的地与当前页面状态。
- 普通日历路由与移动分页均打开 `ModernCalendarPage`。
- 首页将继续观看移到精选前，主栏展示推荐、动漫、电影、电视剧；全部十项频道仍可从更多菜单进入。搜索入口统一为“搜索作品”。Web 不支持 Lumina 时改为浏览电影入口，避免重复无效重试。
- 搜索输入与搜索按钮合并进顶栏；移除搜索区背景插画，筛选选中项增加可见背景。
- 播放详情页使用公共播放按钮，收藏移到标题右侧，简介移至选集后，并可打开完整简介弹层。线路、画质和播放状态管理继续沿用原实现。
- 增加公共按钮和导航末项可达性的聚焦回归用例。
