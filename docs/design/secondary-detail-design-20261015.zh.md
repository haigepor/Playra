## 设计基准

用户认可的 `assets/images/modern-cinema-header-art.png` 的优势是纸张纤维、胶片孔、微弱投影、蓝紫夜景、纸片前后关系，以及大面积透明留白。质感应保存在大尺寸的插画层；18–24px 的操作图标和反复出现的状态符号仍以手写 SVG 或已有一致图标呈现，避免缩小后的纹理变成杂点。

装饰分工建议：**页面标题或首次空态承载材质，卡片承载内容，功能图标承载动作与状态。** 同一屏最多一个主要材质焦点。已有海报的列表不再给每张卡铺胶片、星光或纹理。纸质边缘可以有细节，但不是给所有卡片增加破损边框。

## 五个最值得优先处理的细节

1. **搜索：新比例、来源/资料图标已落地，优先验收小屏密度。** 当前 `_resultTile` 已采用 64/72 宽、1:1.5 海报、14 圆角卡和15字号标题。两张相连资料卡 SVG 表达候选来源，摘要卡 SVG 表达作品资料；候选数量不能承诺可播放。搜索头部已复用认可的影院材质，结果卡保持纯色；下一步检查长标题、来源文案和18px图标的实际阅读效果。
2. **历史：让“第几集、看到哪里”成为第二阅读层。** 观看时间和来源降为第三层；不要添加无总时长依据的百分比进度。现有 28 圆角搜索、24/4 分组轮廓、选中时变形的筛选按钮与新版卡片不一致，先统一同类控件，再补空态插画。
3. **下载：区分六个真实状态，减少重复进度图形。** 目前单集“下载中”同时显示圆形进度和线形进度；统一为一个主要进度表达，旁边显示状态和数值。等待、解析、下载、暂停、失败、完成各有明确符号与文本；下载列表不铺材质。
4. **规则：减少标签与操作竞争。** 现有卡片同时包含名称、版本/策略、多个标签、启用开关和菜单，规则形状还是大圆角。优先突出名称和启用状态，将低优先级技术信息降为一行；卡片左侧最多保留一个类别符号，材质只用于初次介绍或无规则空态。
5. **同步：服务身份、连接状态、操作分开。** 保留已有状态枚举和文字，替换旧四瓣图章的视觉容器。设备与双向箭头可做 SVG；两个服务卡片共用一个小型材质介绍区即可。授权码、URL 和密码表单、错误反馈、删除确认不加背景。

## 接入与验收边界

- 位图应走独立 `artwork` / `Image.asset` 渲染；`SecondaryArtwork` 当前专用于 SVG，并通过 `.32` 的 `srcIn` 统一着色。把纸张位图套入这个思路会损失材质和色彩层次。
- 装饰层使用 `ExcludeSemantics` / `IgnorePointer`，只占预留空间；裁切固定在容器内，不能穿过输入框或覆盖筛选动作。卡片、文本、按钮应保持不透明可读底色。
- 先检查 390 宽和 1440 宽的真实页面，再检查 320 宽、1.6× 字体、键盘弹出、空态和错误态。装饰的退出条件应明确：空间不足时缩小或隐藏，而不是挤压功能内容。
- 本次收尾仅更新本报告与全页面素材映射，未改变图片、SVG、业务、API、页面或测试。本报告保留已接入与未来建议的区分；需要回退时只撤回本次文档差异，不覆盖其他任务成果。
