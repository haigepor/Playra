## 设计结论

保留淡紫品牌、作品封面和四个主导航，把视觉重心集中到作品、观看进度和明确的下一步操作。当前需要优化的核心是信息层级及状态表达。单纯更换配色或增加圆角，解决不了长别名、缓冲含义、缺图和加载失败这些真实数据下的问题。

## 真机证据如何影响设计

| 当前观察 | 设计判断 | 处理方式 |
| --- | --- | --- |
| 真实作品详情的 subtitle 包含很长的中英别名列表，摘要可占多行 | 别名不是用户当前最需要的播放状态 | 主摘要只放当前集数与更新进度，别名收进“作品资料”。缺少更新进度时省略，不用别名填充位置。 |
| 追番记录也能带入相同别名 | 追番页面需要快速判断作品与更新情况 | 固定两行标题区域，优先展示真实更新进度。观看集数、作品更新集数和总集数分别表达，不能互相冒充。 |
| 第二集能恢复并推进到 01:04，但期间多次缓冲 | 首帧成功和流畅播放是不同结论 | 加载、缓冲、暂停、失败分开设计；保留画面和已有资料。未知缓存量显示“正在缓冲”，不长期显示容易误解的 0%。 |
| 部分封面返回 418、404 或连接重置，电脑直连也复现 | 视觉稿不能保证第三方图片始终可用 | 失败占位保留封面比例，用弱对比的图形和作品名，避免整排醒目错误块；不替换成其他作品封面。 |

| 已修复短列表无法到达下一页，以及大字号日历溢出 | 漂亮的正常态不能代替边界布局 | 保留补页与“加载更多”入口；窄屏大字号使用单字星期，读屏保留完整星期。 |

## 页面逐项分析

### 发现

顶部品牌、分类和推荐图应形成一个紧凑入口。Playra 标志使用约 28sp，不把普通页面标题也放大为展示字号。搜索和历史始终保持 48dp 点击区，分类可以横向滚动。

推荐图固定 16:9，标题与播放按钮各有空间，长标题最多两行。推荐图上的渐暗遮罩只服务于文字可读性。继续观看只保留一条主要恢复操作，缩略图、集数、时间、进度条组成同一个可理解的入口。栏目使用轻分隔，不给每一行再套一层卡片。

首页三列海报适用于默认字号的手机。小屏大字号应减为两列；海报比例不能随着列数变化。首屏加载用与内容轮廓一致的骨架；首屏失败显示恢复操作，不能出现无说明的空白。封面失败不会让栏目消失。

### 更新日历

选中日期使用淡紫底，今天使用圆点或边线，两个概念分别编码。星期与日期在同一七列网格内对齐。默认宽度允许“周一”等完整标签；空间不足时切换“一”等单字，语义标签仍读完整星期。

列表按真实更新时间分组，只在组头展示一次时间。每条作品仍应在读屏语义中包含自己的时间、片名和集数，避免第二条以后失去上下文。没有时间的内容单独标为“时间待定”，不能默认填成 00:00。

日期弹层展示当前月份、上一月下一月和明确的取消/确定。月份天数、星期位置、今天和所选日期都从运行时数据生成，不能照抄生成图中的数字。

### 追番与管理

默认手机使用两列，标题区固定两行，更新元信息从同一基线开始。更新角标只标识确有更新的作品。管理操作保持在标题右侧，不占据封面主体。

管理弹层区分打开作品与移除作品的点击范围。“清空全部”继续二次确认，取消与破坏性按钮有清晰主次。空态提供“去发现”，不增加不存在的账号同步或导入功能。

### 我的与网络设置

播放历史、外观、播放偏好、网络与存储、关于形成稳定的阅读顺序。历史数量是辅助信息，不做成醒目的数据面板。系统、浅色、深色控件选中项必须同时有形状和文字对比，不能只靠一点紫色区分。

开关整行可操作，Material 背景与墨水反馈在同一层。网络设置要让“开关代理”和“保存地址”各自有明确反馈。输入错误就近显示，已有地址与开关状态保留。清空历史、清理缓存与只读追番数量不能做成外观完全相同的按钮。

### 搜索

查询词、清空、提交放在同一条工具栏中。结果行展示封面、标题、更新进度、年份地区类别，优先级依次降低。匹配字符使用淡紫强调；大量匹配时也不把整行变成高饱和色。

首次进入未提交、正在搜索、没有结果、首屏错误、后续页错误是五种不同状态。没有结果不提示检查网络；翻页失败保留已加载内容。提交过的关键词和正在编辑的输入要分别处理，翻页不能擅自改为未提交的新词。没有总数时显示“已加载 N 部作品”。

### 分类

标题、四种排序和结果摘要保持紧凑。普通字号手机可用三列，大字号减列，标题和更新行高度一致。不要为现有接口没有的筛选功能预留一排空控件。

排序切换允许保留稳定的容器与加载反馈，但旧请求晚到不能覆盖新排序。后续页面失败使用页脚重试，已显示作品仍能点开。视口扩大或键盘收起后，用户仍可通过“加载更多”继续翻页。

### 详情与竖屏播放

主信息顺序为作品标题、当前集数与更新状态、关键元信息、选集、简介和相关推荐。标题不与收藏按钮争宽度。冗长别名、完整标签和其他资料移到“作品资料”；不要仅用截断隐藏全部语义。

“当前 第 N 集”是稳定的选集说明，播放/暂停由控制按钮表达。正在解析新集时保留旧集状态；如果换集失败，应明确说明目标集加载失败并允许重试，不能把仍在播放的旧集标成新集。首次打开失败与播放中缓冲使用不同的恢复界面。

选集列数由可用宽度与文字宽度共同决定，默认字号约六列，320dp 或 2 倍字号时减少。长集名、缺失集、付费标记沿用真实数据，不能把所有选项都装成两位数字。剧集分组仅在集数确实超过一组时出现。

### 横屏与竖屏全屏

横屏仅在控制区域加遮罩，画面保持原比例。打开选集抽屉时，关闭、线路和剧集按钮留在系统安全区内；抽屉覆盖画面，不能把视频压扁。可触达的进度条不能完全被抽屉盖住。

竖屏全屏以黑色画布保留横向视频的原比例，不把 16:9 强裁成 9:16。锁定模式要有唯一、明显的解锁入口。手势反馈和控制按钮避开底部系统导航区域。

### 历史及其他弹层

历史列表的行点击恢复播放，移除操作有独立热区。播放时间与已观看比例保持一致，未知时长不画虚假的完成率。清空操作保留确认。

播放器选项按高频快捷操作和低频设置分组；倍速选择显示当前值，不为所有条目增加不同风格的嵌套面板。日期、历史、管理、设置弹层共享拖拽柄、标题、内边距和关闭规则。

## 视觉与适配契约

| 项目 | 实施目标 |
| --- | --- |
| 基础色 | 浅色背景 #F7F7FA，主文字 #19191F，次文字 #686873，动作紫 #7043BC，选中浅紫 #EEE8FA |
| 深色 | 背景 #101116，表面 #1B1D25，主文字 #F3F2F7，次文字 #AAA6B6，动作色 #BCA6FF |
| 字体 | 保留 MiSans。页面标题约 28sp，详情标题 24sp，栏目 18sp，作品名 14–16sp，辅助信息 12–13sp |
| 间距 | 默认水平 16dp，使用 8/12/16/24dp 节奏，避免随意增加独立间距值 |
| 比例 | 海报 2:3、横向推荐与视频 16:9；图片下载失败或长标题均不改变比例 |
| 圆角 | 海报约 6dp，控件与容器约 12dp，弹层顶角约 20dp；不把所有元素统一成大胶囊 |
| 点击区 | 主要按钮和图标至少 48×48dp；可见图标尺寸与热区分别处理 |
| 320dp 与大字号 | 标签可读、标题允许增长、内容可滚动；减少网格列数，不整体缩小文字 |
| 平板 | 内容最大宽度沿用现有布局机制，侧栏替代手机底部导航；不把手机页面等比例拉宽 |
| 横屏 | 控制区依据真实安全边距与抽屉可用宽度布局，不能按截图绝对坐标定位 |
| 动效 | 约 120–250ms 的轻量状态过渡；减少动画开启时遵循系统偏好，不能依赖动画说明状态 |

深浅主题使用同一结构，分别定义语义色。正文与交互对比需要在实施后测量，图片中的颜色和字号不是自动合规证明。

## 实施优先级与验收

1. 先统一字号、间距、封面比例和状态组件，防止每页再次各自定义一套尺寸。
2. 处理真实数据的信息问题，尤其是别名、更新集数与观看进度，随后实施发现、搜索、分类和播放详情。
3. 统一追番、历史、设置和日期弹层，再完成全屏抽屉与深色主题。
4. 用 320dp、360dp、平板和横屏验证，字号至少覆盖 1.0、1.5、2.0。检查长标题、缺图、首屏失败、空结果、分页失败和换集失败。
5. 实施继续使用 Flutter 组件、真实文字和原生播放器，不能把整张生成图作为页面背景。真机验收必须达到从入口可达、内容可操作、状态符合实际；不能仅依据截图相似或静态检查通过。
