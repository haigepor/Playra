# 视频 App 参考研究

检索日期为 2026-11-22。本轮按用户要求，通过网络检索并查看官方宣传图、应用商店资料和帮助流程。研究对象为 Netflix、Crunchyroll、哔哩哔哩、腾讯视频。参考用于决定 Playra 的信息层级和操作组织，不复制对方品牌、海报和业务入口。

| 对象 | 当前查阅材料 | 可以支持的判断 |
| --- | --- | --- |

图像检索还出现了 Dribbble 概念稿、旧版教程和第三方截图。本轮未把这些材料当成最新官方界面。没有安装或登录以上 App 做真机流程测试；不同地区和系统的界面仍可能不同。官方宣传图与功能说明分别作为视觉证据和行为证据，结论不混用。

## 对 Playra 的具体转化

| 参考启发 | Playra 采用的设计决定 | 本轮不引入的部分 |
| --- | --- | --- |
| Netflix 的观看主操作与简洁媒体背景 | 推荐图使用高对比播放按钮，紫色主要用于选中、进度和表单主操作。标题、封面和下一步操作成为首屏重点。 | 不加入 Clips、游戏、账户和订阅导航。 |
| Netflix 的继续观看与管理分离 | 首页续播整行有一个主要恢复入口，删除放在历史管理里，避免一个卡片上挤多个同等醒目的操作。 | 不新增服务端推荐和云历史。 |
| Crunchyroll 的动漫视觉和集数上下文 | 海报承担主要视觉，更新时间、当前观看集数和作品总集数明确区分；选集入口靠近播放信息。 | 不搬入语言、配音、会员或独家库等当前源未提供的能力。 |
| 哔哩哔哩所示视频与内容分层 | 播放画面、作品资料、选集、相关内容按区域排序；播放器工具收在操作面板中。 | 不加入点赞、投币、弹幕和评论等新业务。 |
| 腾讯视频说明中的多入口找片和播放工具 | 保留发现分类、搜索、历史、追番的职责，倍速与投屏等既有能力在播放器选项里有稳定位置。 | 不增加会员营销、多层频道和商业化提示。 |

这些是对已查阅材料的设计推论，并非宣称某个竞品采用了 Playra 的具体尺寸。Playra 的 16:9 推荐图、四个主导航和日历仍由自身使用目标决定。例如，官方 Netflix 图中的高主视觉并不直接照搬为更高的首页首屏，以便 Playra 保留续播与更新内容的可见性。

## 统一深色系统

| 角色 | 目标颜色 | 用途 |
| --- | --- | --- |
| 页面背景 | #0C0F15 | 全页与设计板画布，避免大面积偏紫背景 |
| 基础表面 | #151A24 | 设置组、输入框、轻量容器 |
| 抬升表面 | #1D2431 | 弹层与局部选项层 |
| 边界 | #2C3545 | 必要分隔，不能承担唯一状态表达 |
| 主文字 | #EDF0F7 | 标题、正文及重要数值 |
| 次文字 | #A9B1C1 | 年份、地区、非主操作说明 |
| 品牌强调 | #C3AEFF | 选中态、进度、可操作文本 |
| 选中背景 | #34294E | 选集与轻量状态选中面 |

所有主页面、二级页、弹层、空态和标注板均统一深色。设置页保留既有系统/浅色/深色选项，但稿中始终选中深色；这不等于已修改应用的主题设置或删除其他模式。

## 官方平台约束

Android 小屏布局通常以 16dp 水平边距作为起点，并要求重要内容避开系统遮挡区；列数与边距需要自适应。[Android 布局文档](https://developer.android.com/design/ui/mobile/guides/layout-and-content/content-structure)

Flutter 文档要求为系统大字号留出空间，并建议 Android 点击热区达到 48×48dp。它还列出小文字 4.5:1、大文字 3:1 的对比参考。[Flutter 无障碍设计](https://docs.flutter.dev/ui/accessibility/ui-design-and-styling)

安全区需要依据窗口、系统 UI 和屏幕切口计算，不能照抄一张图的固定坐标。[Flutter SafeArea 与 MediaQuery](https://docs.flutter.dev/ui/adaptive-responsive/safearea-mediaquery)

据此，本轮进一步明确日期七列与小屏触区、选集列数与大字号、底栏固定高度与文本增长之间的取舍。具体方案见区域规格，图上的测量线属于设计标注，不应出现在应用 UI 中。
