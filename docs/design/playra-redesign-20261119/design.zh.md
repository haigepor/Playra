# Playra 手机版页面重设计

本版面向用手机找番、追更和续看的用户。四个主入口为发现、日历、追番、我的。原详情与正片播放合为一套手机观看体验：竖屏上方直接播放，下方切线路和剧集；横屏展开为同一视频的全屏视图。演示流单独保留。以下为产品设计提案，原有功能和建议调整分别说明。

## 研究如何改变版面

| 查阅资料 | 观察 | 在 Playra 中采用的做法 |
| --- | --- | --- |
| [Netflix 搜索和浏览](https://help.netflix.com/en/node/47765) | 首页按栏目浏览，主动搜索和分类入口承担不同任务。 | 发现页保留横向内容轨；分类用密集海报；搜索按行并列片名、年份和封面，方便识别同名作品。 |
| [Netflix 继续观看](https://help.netflix.com/en/node/115312) | 继续观看是可独立管理的入口。 | 提议从已有本地历史取最近的可续播作品。无记录时整行收起，完整历史仍由时钟图标打开。 |
| [Crunchyroll 日历](https://help.crunchyroll.com/hc/en-us/articles/22745725145364-Is-there-a-release-calendar-available) 与 [追番列表](https://help.crunchyroll.com/hc/en-us/articles/18184740052628-How-do-I-add-shows-to-my-Watchlist-Crunchylist) | 发行日程帮助查更新，收藏帮助找回个人保存的作品。 | Playra 当前只从首页条目提取周排期，按“每周四”表达；收藏页只读本地收藏。用户点击书签后，两处同步。 |
| [Apple 播放视频指南](https://developer.apple.com/design/human-interface-guidelines/playing-video) | 自定义控件遵循熟悉的播放行为，视频准备完毕即可退出加载。 | 正片和演示共享控件；暂时显示上下遮罩，集数、工具面板按需展开，画面中部留给人物。 |
| [Android 导航布局](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns) | 导航与屏幕空间配合，主目的地与下钻视图分工。 | 本版只交付手机。四个主标签使用底栏，二级页用返回。播放横屏隐藏系统栏和根导航，返回时恢复原页面位置。 |

## 浏览路径与交互归属

- 找片：发现 → 分类或搜索 → 手机竖屏播放页；在顶部视频直接播放，在下方换集或选线路。右下角全屏按钮进入横屏。
- 续播：发现的继续观看或历史弹层 → 校验作品、线路与实际集号 → 在竖屏播放器恢复时间。旧线路失效时，保留页下选集和可用线路。
- 追更：日历 → 查每周排期 → 添加书签或进入详情；追番 → 从本地收藏重新打开作品。
- 设置：我的 → 播放偏好、网络、本地数据、关于。演示页为独立测试入口，可置于关于区域二级菜单，供验证播放能力。
- 数据归属：作品、线路、剧集和排期来自内容源；收藏与进度来自本地 Hive；播放时长、播放位置和是否已经起播由播放器确认。页面不能靠装饰文案推断这些状态。

## 逐页功能与设计决策

| 页面 | 现有功能和数据 | 首屏布局与主任务 | 二级操作、边界和文字取舍 |
| --- | --- | --- | --- |
| 发现 | 轮播、分类、栏目、搜索、播放历史、日历入口；栏目和分类由 CliCli 分别返回。 | 字标及搜索、历史入口 → 分类短栏 → 通栏作品剧照 → 有记录才显示续播轨 → 热播作品轨。点主视觉进入详情，点续播可恢复已确认的进度。 | 日历在底栏始终可达。每个海报至多一条集数信息。仅有有效栏目查询时给“更多”；不使用空分类打开与标题不符的列表。外链没有目标时不呈现播放动作。首页出错保留搜索与历史。 |
| 日历 | 周条、切周、月份选择、日排期、时间、详情、单条追番、刷新。排期取自首页作品的更新描述。 | 月份切换 → 七日日期条 → 星期分组 → 按时间排列的节目行。时间、片名、集号、书签各占独立列。 | 月份选择用日期面板；缺时间写“待定”。只有周期依据时标“每周四”，不宣称某日已上线；网络失败隐藏数量，成功且为空才显示无排期。书签绑定作品 ID。 |
| 追番 | 本地收藏、按收藏时间排序、进详情、清空确认。 | 标题、真实数量、“管理” → 双列大海报。两列让封面和片名有足够辨认空间。 | 管理模式提出单项移除，清空仍需确认。空态只给“还没有追番”和“去发现”。日历能否看到一部作品取决于排期数据。 |
| 我的 | 主题、硬解、续播、自动下一集、音量亮度手势、HTTP 代理、本地历史和收藏数量、清历史、清图片内存、许可及内核致谢。 | 高频历史入口提前；外观用三段选择；播放偏好用单行开关；网络、存储、关于向下滚动或展开。保留系统、浅色、深色三种偏好，样稿展示深色。 | 代理地址仅在支持自定义代理且启用后出现。数据清理分别写“清空历史”和“清理图片内存”，并区分影响。版本与致谢收进关于。版本号、数量由运行时提供。 |
| 搜索 | 按词提交、清空、分页、首屏重试、翻页重试、跳详情。 | 返回、输入框、清除、提交同一行。结果用单列小海报、完整片名、一行年份/类型，便于区分相似结果。 | 已输入的词只显示在输入框。首次进入唤起键盘，成功态关闭键盘；无结果显示“没有找到相关作品”。清除或新提交使旧请求失效；翻页失败保留已加载结果，在列表末尾重试。 |
| 分类 | 接收来源与分类 ID，四种排序、分页、下拉刷新、进详情。 | 分类名 → 单行排序 → 三列竖海报。封面、片名和可选集数是浏览单元，评分排序只在数据存在时补评分。 | 排序切换后结果必须对应当前高亮项；慢请求不能混合两种排序。页脚负责翻页反馈。返回保留分类、排序和位置；未能获取总量时不显示“共 N 部”。 |
| 竖屏播放与作品信息（承接原详情） | 复用详情元信息、书签、线路、实际剧集、断点记录，并把正式播放器置于首屏。 | 状态栏 → 通栏 16:9 视频（390dp 宽时约 219dp 高） → 片名、当前集和书签 → 线路及选集 → 可展开的作品信息。暂停、时间、进度和全屏都在播放器内。 | 点击某集在当前视频窗口切换；仅当新集成功起播后更新“正在播放”。历史有效才恢复时间。点击简介展开补充年份、标签、评分等真实字段。底部无需再次给启动播放按钮。 |
| 横屏全屏播放（同一观看会话） | 内容源解析、断点、切集、连播、播放速度、进度、比例、截图、手势，以及平台支持的画中画、投屏、外部播放、超分与定时关闭。 | 画面全屏，轻触唤出上下控件；从右侧抽屉选集，中央留给作品。 | 左上返回或退出全屏回到同一竖屏页。进度、集号、线路、倍速、暂停状态连续。低频工具收进更多；切集失败保留旧片和进度；截图候选单独审阅。 |
| 播放演示 | 独立公开 HLS 测试流，复用播放器，三个演示集共用测试地址。 | 手机横屏满幅示例片，左上“播放演示”和小型 HLS 标记，底部与正式播放使用同一套控件。 | 测试片信息和地址折叠，错误时给“重试”“返回”。演示不创建追番记录。稿中的帆船画面与时长是美术选样；实际画面和时长取决于测试流。 |

## 文案删减和必要反馈

| 情境 | 显示 | 收起或删除 |
| --- | --- | --- |
| 有内容的发现页 | 可点的作品名、栏目名、进度 | 欢迎语、品牌宣言、栏目简介、连续重复的同一标题 |
| 搜索结果 | 输入词、完整片名、用于区分的年份/类型 | 页头再次复述“某某的搜索结果”；无依据的热词 |
| 设置开关 | “断点续播”等操作名及开关状态 | 逐行解释开关用途。仅首次涉及系统权限或不可恢复操作时补一句影响 |
| 日历 | 周期、已知时间或“待定” | 推断钟点、加载失败时的“0 部”、未获确认的“已更新” |
| 收藏为空 | “还没有追番”“去发现” | 教程式长段落，以及收藏必然出现在日历中的承诺 |
| 播放错误 | “播放失败”“重试”；切集失败时提示原片仍可观看（仅在确实仍播放时） | 完整异常堆栈、常驻网络说明和重复弹窗 |
| 破坏性操作 | “清空全部追番？”、“取消”、“清空”；必要时写“只影响本机收藏” | 模糊的“确认”、含糊的“清理全部数据” |

## 手机规格与素材交接

- 竖屏设计基准 390×844dp，复核 360dp 宽设备和大字号。播放器基准 844×390dp，安全区内放控件；较窄时优先收起倍速和低频菜单选项。内容长到需要滚动时允许自然裁切下一行。
- 正文区左右 20dp，目录列距 8dp，大海报列距 10dp。列表片名允许两行；设置可增长行高。搜索结果优先显示完整片名，网格保证同排封面对齐。底栏图标加文字，浅紫同时配合实心、描边或下划线表示选中。
- 黑色表面用于承载媒体。播放画面仅上下边缘加遮罩；亮场、暗场测试以返回、时间、拖动滑块始终可读为准。浅色主题复用结构，改用浅底和深文字；调色不改动封面原色。
- 首页宽幅主图使用环境和人物的关系讲作品；横幅与竖海报分别构图。安全裁切区应包住人脸、围巾或夹克等辨识特征，预留片名区域。续播轨使用横向集内剧照，避免与下方竖海报重复。
- 海报不烘焙片名、评分、角标或按钮。真实信息由 Flutter 叠加，可缩放、切换语言和响应状态。片名、导航、选集、时间和按钮以提示词中的文案为准。
- 加载保留既定图片比例，首屏加载用占位块；缩略图单独失败时保留片名及进入详情的能力。日历和收藏行的书签需要同时具有可读语义和至少 44dp 的点击区。
- 布局稿以原创剧名《夜航线》《雾山来信》等串起发现、收藏、详情与播放。示例数字与剧情只用于看层级；不对应 Playra 的实际库存、播放进度或推荐算法。

## 弹层和极端状态

| 入口 | 呈现和返回行为 |
| --- | --- |
| 历史记录 | 手机半屏底表；每条保留封面、作品、集与进度，单条移除有独立触点；关闭返回原标签。 |
| 日历月份与切周 | 日期选择器确认后将所选日带回周条，取消保持原位置；来源暂缺条目只影响节目单。 |
| 选集、线路、倍速与截图 | 播放中选集 / 线路按组显示，当前播放有标志；倍速和比例使用短菜单；截图候选页可预览、挑选与保存。 |
| 缺少参数 | “无法打开此页面”配“回到发现”，按钮直接到根入口，适用于没有上一页的情况。 |
| 存储初始化失败 | 独立启动失败界面，只给原因及重新启动的说明；初始化成功前不渲染四标签和业务按钮。 |

## 实现对照

两种方向共用一套会话，横屏不会重复解析或从零重播。竖屏点击视频右下角全屏进入横屏；横屏按返回，先关闭选集或更多面板，再退出全屏。发生来电、切后台或方向切换时，继续沿用原播放状态及平台音频策略。拖进度只显示目标时间，松手提交。退出后恢复原滚动位置。全屏入口与退出路径参考 [YouTube 手机端全屏说明](https://support.google.com/youtube/answer/72689?co=GENIE.Platform%3DAndroid&hl=en)，抽屉宽度、文案和状态恢复是本项目的设计决定。
