# 页面素材尺寸与层级调整

## 原因与设计

原图为 2172×724，左半部分主要是透明留白。原主页面把整张图限制在 48～54 高度，完整主体随之缩小，形成右上角的小贴图。搜索页另外使用 `BoxFit.cover`，不同页头高度会裁切主体。

本次保持既有纸艺图片与原始生成提示词，采用完整比例背景层。画布宽度为内容宽度的 1.6 倍，上限 1020，高度为宽度的三分之一；超出页面左边的主要是原图透明留白。背景先绘制，原有前景内容后绘制，卡片自然遮挡其下层素材。背景不占用布局、不参与点击、不进入读屏。

## 页面检查范围

| 页面 | 结果 |
| --- | --- |
| 发现 | 影院素材扩大至背景尺度，390 宽度时画布 624×208，透明度 0.20，导航与列表位于上层。 |
| 日历 | 同一背景组件，独立日程素材，透明度 0.16；星期、季度和筛选仍为前景。 |
| 追番 | 同一背景组件，独立片单素材；背景与 1200 最大内容区域右侧对齐。 |
| 搜索 | 移除页头 `cover` 与竖向遮罩，使用全内容区域下层背景，搜索与分类保持可操作。 |
| 我的 | 非空观看足迹素材从 342×114 放大到 480×160，卡片最小高度 176；空足迹的 SVG 引导保留。 |
| 历史、下载、规则管理/编辑、同步 | 共用介绍卡片的背景画布扩大至 600 宽，受卡片高度约束时等比完整缩放，最低卡片高度 144，透明度 0.16。 |
| 历史/下载空状态 | 单独的空状态插画已有独立尺寸与构图，保留。 |
| 播放页 | 功能 SVG、空状态和线路装饰没有同类 PNG 页头缩放问题，保留。 |

## 修改与回退

- `lib/presentation/modern/widgets/modern_page_art.dart`：主页面尺度与共用 `ModernMaterialArt` 图片层。
- `lib/presentation/modern/pages/content_search_screen.dart`：搜索内容整体下层素材，去除局部裁切。
- `lib/presentation/modern/profile/modern_profile_view.dart`：足迹卡片素材尺度。
- `lib/presentation/modern/secondary/utility_page_art.dart`：工具页介绍卡片尺度。

修改前副本位于 `.dart_tool/material-background-backup-20261015/`，按原相对路径保存。工作区有其他任务改动，回退时仅撤销本次差异，避免整文件覆盖。无接口、依赖或数据变更，无新图片生成。
