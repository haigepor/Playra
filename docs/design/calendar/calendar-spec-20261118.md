# Playra 日历页设计规格（2026-11-18）

> 设计稿：`docs/design/calendar/calendar-phone-light-20261118.png`、`docs/design/calendar/calendar-tablet-portrait-20261118.png`  
> 目标页面：底部导航「日历」  
> 视觉系统：延续首页 lavender editorial，背景使用 `home-decoration.webp` 装饰纹理

## 1. 页面目标

把日历页从占位页升级为「追番更新日历」：

- 按周查看动画更新安排；
- 快速定位今天和本周更新时间；
- 一眼判断是否已追番、是否已更新；
- 手机端底部导航；平板端使用 72dp 侧栏。

## 2. 信息架构

```
追番日历
├── 顶部栏：品牌 / 页面标题 / 月份选择 / 日历图标
├── 周视图：周一至周日 + 日期 + 今天标记 + 更新圆点
├── 今日摘要：今日更新 8 部 · 本周 24 部
├── 更新时间轴
│   ├── 19:00  星云彼岸的旅人  第 8 话  更新  追番
│   ├── 20:00  遗迹之上        第 8 话  更新  追番
│   ├── 21:30  魔法学园日志    第 8 话  更新  追番
│   └── 23:00  终焉之树        第 8 话  更新  追番
└── 底部导航：发现 / 日历（选中） / 追番 / 我的
```

## 3. 手机端规格

| 区域 | 规格 |
|---|---|
| 页面 gutter | 16dp |
| 顶部栏高度 | 44–48dp |
| 月份选择 | 纯文字按钮，高度 36dp，右侧箭头 |
| 周视图 | 7 等分，高度 64dp；今天使用紫色圆形日期底 |
| 日期字号 | 日期 17sp，星期 11sp |
| 摘要行 | 高度 36dp；标题 16sp，数量 18sp，本周为次级文字 |
| 时间轴时间列 | 42dp，时间 14sp，使用品牌紫 |
| 更新时间列表 | 单一半透明白底容器，圆角 14dp；行间细分隔线，无卡片阴影 |
| 时间轴行高 | 80dp（含 8dp 上下内边距） |
| 海报缩略图 | 48×64dp，圆角 9dp |
| 标题 | 14sp / w600 / 单行省略 |
| 集数 | 11sp / 次级文字 |
| 追番按钮 | 34×34dp，仅铃铛图标 |
| 底部 Dock | AndroidLiquidGlass 原生，48dp 外层 / 40dp Tab |

## 4. 平板端

- 72dp 左侧栏，日历为选中项；
- 单行工具栏：品牌 + 追番日历 + 月份选择 + 日历图标；
- 周视图横向铺满内容区；
- 更新时间卡片使用两列布局，列间距 16dp，单卡仍保留时间列；
- 内容最大宽度 1000dp（竖屏）/ 1200dp（横屏）。

## 5. 交互与状态

- 点击周日期：切换到该日时间轴并滚动回顶部；
- 左右滑动周视图：切换上一周 / 下一周；
- 点击月份：弹出年月选择器；
- 点击追番按钮：切换追番状态，使用 Hive 本地持久化；
- 点击卡片：打开媒体详情页；
- 下拉刷新：刷新日历数据；
- 空状态：显示「这一天暂无更新」+「去发现」；
- 加载状态：保留周视图骨架 + 3 条时间轴骨架；
- 网络异常：保留当前缓存数据，顶部显示轻量提示。

## 7. 数据契约（实现前需补齐）

日历页需要独立于首页 feed 的更新时间数据：

```text
CalendarDay
  date, weekday, releaseCount, isToday, hasUpdates

CalendarRelease
  id, title, coverUrl, episodeLabel, airTime,
  status (updated/upcoming), followed, sourceId, detailRoute
```

后续实现时应先接入真实来源；没有数据时使用空状态，不伪造更新时间。
