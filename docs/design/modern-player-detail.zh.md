# 播放与详情一体页：交互细化与 SVG 素材

日期：2026-10-11。当前核实项目：`D:\project\Playra`；旧设备路径不再作为命令依据。

原交接只有六个 SVG 初稿，没有 HTML/PNG 预览或 Flutter 验收。当前已补充素材预览和第二稿交互设计；用户已否定第一稿视觉，因此第一稿不能作为最终接入依据。页面行为仍按本文实施，进度见独立 OpenSpec `modern-player-detail`。素材通过解析不等于页面或媒体播放验收完成。

## 第二稿视觉方向

采用紧凑的影音信息密度：播放器独立固定；标题、评分、元信息集中；简介就近进入；追番为主操作，下载和更多降为轻量操作；来源与线路直接成行，避免每块内容套描边卡片。当前集附近横排，全部剧集在弹层内查找。颜色继续复用现有主题，正文 14、标题 21、辅助 11–12，操作目标不小于 48。

第一稿取景框、打板和搜索放大镜改为低对比远景、胶片与圆角气泡。无封面时明确占位，不把示意画当真实封面；有封面时使用真实资源。资料区装饰是可选项，默认优先保证文字可读，不强行贴到每个标题后面。

- `modern-player-preview.html`：完整可交互第二稿，含 320/390/430 宽度、1/1.5/2 倍字体、选源/空/错误状态、三标签、简介与选集弹层、评分隐藏/无投票。
- `modern-player-assets.html`：独立素材与实际尺寸空状态预览。
- 所有 HTML 样例数据已明确标识；没有真实媒体初始化或业务写入。
- 浏览器已检查 320 宽/2 倍字体选集弹层：无横向溢出、三列、按钮均至少 48 px、关闭后焦点恢复；评分隐藏后区块不占位。

## 页面骨架

手机竖屏：安全区 → 固定 16:9 播放区域 → 固定的详情/讨论/评价标签 → 当前标签独立滚动内容。播放器和标签都在内容滚动容器之外，无需再叠加第二套吸顶逻辑。详情页不展示根页面的底部四个导航项。

详情内容顺序：标题、评分与简介入口 → 元信息 → 追番/下载/更多 → 来源与线路 → 剧集横向预览与全部选集 → 关联作品。标题允许两行；长内容、大字体下自然增高。

采用现有主题：背景 #11141C、卡片 #1B202C、强调 #A7B7FF、正文 #EDF0F8、次级 #A5AFC5、边框 #30384A。标题 20–22 dp、正文 14 dp、辅助文字 12 dp；标准图标 18–20 dp，点击范围至少 48 dp。资料区不使用大片模糊海报或高亮光斑。

## 需要优先处理的细节

### 1. 进入与加载是多个独立状态

| 状态 | 播放区域 | 下方内容 / 恢复操作 |
| --- | --- | --- |
| 只有作品资料 | 封面；无封面时用播放器占位；真实按钮覆盖其上 | 资料可读，播放按钮进入选源 |
| 搜索来源 | 轻量状态文案，避免整页骨架闪动 | 可取消搜索；资料保持可读 |
| 待验证码 | 明确当前来源与验证入口 | 可换源；取消后回到该来源状态 |
| 已选集、解析中 | 显示目标集标题与进度提示 | 目标集呈选中态，不显示“正在播放” |
| 缓冲 / 播放 / 暂停 | 由现有播放器真实状态驱动 | 播放标记只在实际播放时激活 |
| 解析失败 | 原位错误、重试、换源 | 保留已选作品和剧集，不整页重置 |
| 离线文件缺失 | 文件不可用状态 | 重试或返回下载；不自动冒充在线来源 |

加载作品资料、来源列表、播放解析和讨论互不阻塞。资料 API 失败不应强制停止已播放媒体。没有来源时不显示“第 1 集”假数据，不用“0 集”暗示已完结。

### 2. 播放器生命周期是首要约束

一体页持有一个播放会话；未选源时暂不初始化媒体。资料与播放会话分开管理，通过显式回调接入选源结果，不能直接把两个旧页面嵌套。

切标签、打开简介/选集弹层、刷新评论不改变播放器 key，也不调用重新加载媒体。已有 `_playbackSessions` 等失效保护继续复用；快速点击多个剧集只允许最后一次有效请求更新界面。

当前代码切集会停止旧媒体，因此设计不承诺“切集解析时旧画面持续播放”。需要无缝换源时另做播放器能力验证。

保留已有在线、离线路由适配入口。统一外观不意味着立刻移除 `/info/`、`/video/` 或改写历史记录格式。

### 3. 来源、线路和剧集有不同身份

来源入口展示站点真实名称；线路胶囊使用来源返回的名称。未经检测不标注蓝光、4K、高速等质量承诺。

打开选集时，临时浏览另一条线路不立即中断当前视频，确认某一集后才切换。自动跨源恢复必须结合原始剧集标识、标题、集数、正片/特别篇属性确认，不能仅靠列表位置；无法可靠匹配则让用户选择，并明确是否从头播放。

升降序只重排视图，回调仍传原始 EpisodeRef 对应索引。SP、OVA、预告、合集保留真实标题；不要用统一“第 N 集”覆盖。

### 4. 选集有两种密度

页面内横向预览显示当前集附近内容并提供“全部选集 ›”。底部弹层默认约 80% 可用高度，最高约 92%；具体受安全区与短屏约束，不按整机物理高度计算。

弹层固定标题、当前线路、排序与分段入口，下方网格独立滚动。常规宽度四列，窄屏/大字体减少列数。50 集一段是展示分组，不是假分页请求；数百集使用惰性构建。

选中态用边框和背景；正在播放增加三竖条标记，暂停保持选中但不律动；下载完成使用独立小图标。不要同时叠加多个彩色角标。已看进度必须来自历史，不能仅凭打开过一集判定看完。

每次打开默认定位当前集；排序不更改选中身份，切换线路或分段从新段顶部开始，另设“定位当前集”，避免不断抢回滚动位置。

### 5. 评论与评分不混淆

讨论标签说明“本集讨论”，展示真实匹配集标题；明确区分未匹配、空讨论、请求失败。切集后通过既有版本检查丢弃旧评论结果。

评价标签对应整部作品的评分和短评。项目评分按源数据尺度显示，不将参考图的五星分布直接套到十档评分数据。无投票时不计算除零百分比，隐藏评分设置应同时约束详情与评价区。

参考图的发送弹幕、楼中楼、点赞、热门排序、评论计数不等于已有接口支持。待逐项确认授权和后端能力再显示交互入口，不添加不可用的输入框。当前用户已选择暂不配置弹幕 AppId/AppKey，此限制继续保留，不能把缺凭据显示成网络故障。

### 6. 操作和推荐保持真实

追番展示真实状态，重复点击防抖，失败保留或恢复正确状态。下载入口先检查平台、来源、离线状态与服务能力。分享、反馈等入口只有现有实现可用时才纳入。

优先显示关联作品，不将任意热门列表标为“猜你喜欢”。未来接入推荐需明确数据来源，过滤当前作品、去重并设定数量上限。

首播日期、资料库放送时间、来源剧集更新时间是三种不同信息；只显示确有数据的字段。未知时间不使用推测值，长信息允许折行。

### 7. 安全区、键盘与返回

状态栏采用深色保护背景，播放器控件避开刘海；沉浸全屏使用已有系统栏逻辑。竖屏常规保持 16:9，横屏进入适合的播放布局；大字体或键盘压缩空间时，确保弹层标题、关闭与主要操作仍可见。

返回优先关闭最上层弹窗/选集、退出全屏，再离开一体页；不得重复消费返回导致退出应用。弹层打开后焦点留在弹层，关闭恢复到触发按钮。推荐默认打开普通资料弹层不中断播放；进入需要输入的编辑表单时应明确约定暂停策略，关闭时仅恢复由该表单主动暂停的播放。

切后台、音频焦点、画中画、旋转及 Web 用户手势播放约束沿用现有平台策略，页面视觉改造不另建一套播放策略。

### 8. 动效和无障碍

标签指示器可用 180–240 ms 过渡，文字直接切换粗细/颜色。尊重减少动态效果。播放竖条素材本身静态，只有 isPlaying 且界面可见时才由 Flutter 驱动；暂停、缓冲、后台不持续律动。

装饰 SVG 使用 IgnorePointer 并从语义树排除；空状态文字和按钮由真实 Widget 提供。播放状态使用文字或语义标签辅助，不能只用颜色和动画表达。

## 六个资源及接入规范

资源均在 `assets/images/`，不包含字体、脚本、外链、嵌入图片、滤镜或内置动画。

| 文件 | 尺寸 | 使用位置 |
| --- | --- | --- |
| modern-player-placeholder.svg | 480×270 | 无封面的播放器待播放态；真实播放按钮叠在中央 |
| modern-player-poster-placeholder.svg | 120×168 | 关联作品封面缺失；外层继续按组件裁切圆角 |
| modern-player-empty-source.svg | 160×112 | 来源列表确实为空；请求失败使用具体错误文案 |
| modern-player-empty-discussion.svg | 160×112 | 讨论加载成功且为空；错误和未匹配不能混用 |
| modern-player-playing-mark.svg | 24×24 | 当前播放集，建议绘制 14–16 dp；适当搭配状态文案 |
| modern-player-detail-decoration.svg | 360×120 | 资料区右侧可选装饰，填充 2.5%、轮廓 9%–14%；Flutter 默认不铺到标题后面 |

SVG 默认使用固定主题色以保证直接打开可见。单色播放标记可通过 `SvgPicture.asset(..., colorFilter: ColorFilter.mode(color, BlendMode.srcIn))` 替换颜色；多色占位/插画不要整体染色。具体接入时以项目安装版本 API 为准。

播放器占位用 BoxFit.cover；空状态插画用 BoxFit.contain；信息区装饰不覆盖播放器、文字或按钮，不再次叠加强透明度导致不可见。SVG 中不写文字，语言、状态、交互、焦点都交给 Flutter。

## 六个素材逐项审查结论

| 素材 | 初稿结论 | 第二稿结果与理由 |
| --- | --- | --- |
| 播放器占位 | 替换 | 通过：480×270 的远景与暗色渐变，减少中心框线，给真实按钮和封面留出空间。 |
| 海报占位 | 替换 | 通过：120×168，与播放器同一图形语言；60×84 和实际关联卡片裁切可读。 |
| 空来源 | 替换 | 通过：胶片、小减号，表达来源缺失；只用于搜索成功且为空。未配置来源和请求失败使用具体文字。 |
| 空讨论 | 替换 | 通过：圆角气泡、三点和低对比后层；只用于真实匹配后加载成功且为空。 |
| 播放标记 | 通过 | 保留：14/16/24 尺寸可辨识，可按主题染色；静态标记只在真实 playing 与当前剧集一致时显示，暂停/解析时移除。 |
| 资料装饰 | 替换 | 通过：右侧轻描边图形，左侧保留文字空白；可选素材，当前 Flutter 默认不用，避免多余装饰。 |

全部 SVG 使用基础路径、圆形及必要渐变，不含文字、脚本、外链、嵌入图片、滤镜或动画。多色插画保持原色；装饰与插画从语义树排除，文案和操作由 Widget 提供。独立和 320/390 尺寸上下文见 `modern-player-assets.html` 与 `modern-player-assets.png`；完整第二稿见 `modern-player-preview.html`。
