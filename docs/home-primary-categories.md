# 首页主分类

主导航：推荐、热门、动漫、电影、电视剧、综艺、漫剧。

推荐和热门是内容分发入口，其余是内容分类。选中文字 16px、未选中 14px，取消文字动画，保留下方 20×3px 圆角横线的滑动。导航高度 42px，PC 导航宽度最多 420px，小屏或大字体可横向滚动。

动漫下为全部、新番、日漫、国漫、动漫电影。目录候选与 Bangumi 元数据联合归类，算法和边界见 [首页分类与数据分配](home-data-distribution.md)。电影、电视剧、综艺、漫剧目前只建立主要分类入口，显示“内容即将上线”；不将动漫结果复制到这些分类。切换时使旧请求失效，避免异步结果串到新分类。

建议下一批优先考虑纪录片和短剧。纪录片的内容形式与电影/电视剧不同，适合独立入口；短剧对应独立观看习惯，可单列。少儿更适合年龄筛选，音乐可先归入综艺或演出子类；体育和直播需先确认相应内容源，再决定独立入口。动作、喜剧、科幻、悬疑、爱情等属于题材筛选，后续放到分类内部，不占主导航。

本次修改文件：modern_home_controller.dart（分类与数据隔离）、modern_home_view.dart（主导航、动漫子分类与待上线状态）。仅重建 Web 预览并刷新，不运行测试，按用户要求手动体验。

回退副本：.dart_tool/home-primary-categories-controller-baseline.dart、.dart_tool/home-primary-categories-view-baseline.dart。
