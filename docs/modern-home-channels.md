# 紧凑频道首页

范围：仅 `lib/presentation/modern/home/`、新版发现页的数据接线、新版导航在首页的暗色处理、对应首页/导航测试及本文。基线 `adce00db`；逐文件备份 `.dart_tool/home-channel-baseline/`。已有其他工作区改动保留。

验收：去掉品牌、历史和主题按钮整行及大标题；频道滑块在上、搜索与排期表在下；独立横滑栏目；封面左上评分、右下无背景的放送星期/时刻；栏目右侧可点击“查看更多”；取消首页分页入口。沿用 Flutter、shadcn_ui 和既有业务路由，无新增依赖，不改旧版或持久化模型。

数据：今日推荐使用当前榜单，国漫/日漫使用中国/日本标签查询，镜像空分类自动回退官方搜索。日历分组是放送星期的来源，不能将首播日期推算的星期当作每周更新时间。精确时刻仅从条目明确的放送时间字段读取；缺失显示待定。资料放送时间按原播出地标注，不等于资源站更新承诺。多个不同放送时刻与 24+ 小时记法暂不推算，以待定显示。

Tab 使用 Flutter 的 CupertinoSlidingSegmentedControl，并沿用首页颜色和字体；原生连续拖动、点击吸附，避免使用静态 SVG 模拟交互。参考：https://api.flutter.dev/flutter/cupertino/CupertinoSlidingSegmentedControl-class.html

验证：首页状态、独立栏目的失败恢复、滑块拖动、横向滚动、缺失时间、大字体、小屏、明暗主题、详情入口以及 Web 实际预览。

最终视觉：新版首页与首页的底部导航固定暗色；时间不显示提示框、背景块或文字阴影。封面底部 36% 高度覆盖从 31% 黑色逐渐到透明的遮罩。PC 指针进入封面时以 240ms 缓动放大到 1.04 倍，退出恢复；动画裁切在封面圆角内，角标保持稳定，卡片 hoverColor 为透明。系统关闭动画时不播放缩放过渡。

已完成：28 项相关测试通过，修改范围静态检查无问题；9 个文本文件通过严格 UTF-8/无 BOM/无替换字符检查，`git diff --check` 通过。官方中国标签查询实测返回 20 项。浏览器截图与构建结果在实际验收后补充。
