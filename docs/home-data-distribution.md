# 首页分类与数据分配

日期：2026-10-11。范围：新版首页、动漫子分类及其“查看更多”。旧版首页、规则搜索/播放协议、Hive 模型不变。

## 数据调查结论

项目使用 Flutter / Dart。规则 `Plugin` 的搜索结果是 `SearchItem(name, src)`，没有标准化的首页分类、地区、封面、年份字段，因此不能把规则搜索列表直接当作完整首页资料。会话内的规则成功状态也不能代表长期稳定性。

本次读取两个 Web 预览 origin 的规则存储时，已安装列表为空。项目自带 DM84 和 7sefun 配置均存在；通过现有 Web 代理读取它们的首页均获得 HTTP 200，DM84 的国漫、日漫、电影目录也获得 200。DM84 首次首页读取约 7.2 秒，7sefun 约 5 秒；这些是本次网络快照，不能据此断言永久稳定或视频可播放。

选择：优先读取已安装且已有目录适配器的规则，支持 DM84、7sefun，保留用户规则顺序；没有这两种已安装规则时读取项目自带配置，优先 DM84，失败回退 7sefun。不自动安装规则、不修改用户配置。当前只有这两种目录适配器，其他规则仍沿用原搜索/播放能力。

DM84 目录覆盖国漫、日漫和电影，适合当前动漫首页。但其电影目录混有 OVA / 特典，不能以“出现在电影栏目”作为唯一分类依据。例如目录中的《大贵族：回醒》《魔卡少女樱特典》需要经过官方资料确认。Bangumi 的“中国”标签搜索样本 20 条也包含 5 部剧场版、3 部 TV、12 部 WEB；仅按“中国”搜索会使国漫与动漫电影混杂。

官方动画电影日期榜的首批日期出现 2027–2029 年。本实现按近三年分别补齐日期候选，并在本地过滤已知未来上映日期，避免尚未上映作品占据推荐位。

当前加速镜像 `/v0/subjects` 和 Next 趋势路由返回 404。新增电影目录、趋势候选请求单独通过现有 `apiDio` 访问官方接口，仍保留网络代理设置，不修改全局加速配置；其他资料请求沿用原有传输。

## 数据链路

1. 规则目录：首页及最多三个地区/电影目录，解析名称、站内详情链接及目录来源。每页最多 40 条，不抓取播放页。
2. 资料候选：Next 动画趋势、放送日历、官方中国/日本动画搜索、官方电影评分榜、近三年动画电影日期榜。每个资料请求最多 40 条。
3. 规则名称与 Bangumi 中文名、原名、官方别名规范化后严格匹配。仅去除标点、明确画质标记，并统一第一季/第1季等写法；保留季、篇等身份。
4. 每个规则目录取前三个尚未匹配的候选补查资料，最多 12 个名称；同名多个候选不自动选择，防止重制版/不同季串片。其余未匹配条目暂不强行展示。
5. 用 Bangumi ID 合并条目，完整 v0 资料优先于 Next 摘要，再分类、排序、分配栏目。

目录收录标记只影响推荐优先级。它表示本次目录快照存在明确名称匹配，不表示已经验证播放，也不绕开原有搜索/选源流程。资料不足时允许以可靠元数据补足栏目，不伪造封面、分类或更新时间。

## 分类口径

所有候选首先要求动画 `type=2`、有效 ID、名称、HTTP(S) 封面，并排除 NSFW 和已知未来首播/上映日期。

| 子分类 | 纳入条件 | 排除条件 |
| --- | --- | --- |
| 全部 | 明确 TV / WEB / OVA 系列动画，或明确动画 Movie / 剧场版 | 类型不明、真人内容 |
| 新番 | 当前自然季度已经首播的 TV / WEB 动画 | OVA、电影、未来首播、缺少日期 |
| 日漫 | 系列动画，国家元标签明确且仅为日本 | 动画电影、地区不明/冲突 |
| 国漫 | 系列动画，国家元标签明确且仅为中国 | 动画电影、地区不明/冲突 |
| 动漫电影 | 动画且平台明确为 Movie / 剧场版 / 电影 | TV / WEB / OVA，单凭站点电影目录不能纳入 |

官方动画浏览接口 `type=2&cat=3` 对应 Movie。地区判断使用 `meta_tags` / `metaTags`，不从中文标题、用户搜索词或普通题材标签推断。地区未知但形式明确的作品可以进入“全部”的“更多动画”。

“新番”指当季首播，长年连载不因日历里仍有放送就被算成当季新作。

## 排序与栏目分配

推荐分：`0.35 × 评分可信度 + 0.20 × 热度 + 0.10 × 新鲜度 + 0.35 × 规则目录收录`。

- 评分可信度：贝叶斯收缩，先验为 250 票、6.8 分，避免只有少数评分的条目直接排第一。
- 热度：对评分人数与收藏总量中的较大值取对数，按候选池最大值归一化。
- 新鲜度：按首播/上映距今天数指数衰减，衰减尺度 180 天；缺少日期时使用较低的新鲜度。
- 规则目录收录：严格匹配本次可读取目录的条目优先。热门频道以归一化热度排序；相同分值按 ID 稳定排序。

“全部”的推荐位采用分组轮询：当季新番 2、国漫系列 2、日漫系列 2、动漫电影 1，重复循环；不足的组跳过，剩余其他地区动画补齐。按 ID 去重，避免某个类别占满推荐位。

推荐/热门页面先给 12 个综合条目，再按当季新番、国漫、日漫、动漫电影、其他动画分栏；已分配条目不再进入另一展示栏。子分类页面分别生成当季新番、地区新番/精选/更多、近年电影/精选/更多。每条横向展示栏最多 20 张，剩余同栏数据通过“查看更多”展开。

“查看更多”直接展开栏目快照，不重新做更宽泛的标签搜索，因此条目类型、筛选口径、顺序与栏目一致。首页没有触底无限加载。

## 时间、请求与回退

番剧右下角星期取放送日历分组，时刻只取明确且唯一的放送时间；资料缺失保留“待定”，不把首播日期计算成每周更新时间。动漫电影显示 `MM-dd上映`，不套用每周放送格式。

目录与资料读取有超时，资料任务分组执行、补查最多三个并发，详情时间只对可见海报补查。频道切换复用同一资料池，刷新重新读取；旧请求不能覆盖新的选中分类。资料源部分失败时仍展示其余有明确分类的内容；整池失败保留上次成功资料，首载完全失败时显示重试状态。日历失败保留上次日历。

## 推荐金刚区与固定导航

推荐频道使用四张同款横向小卡，按两行两列排列；每张卡左侧为竖版缩略图，右侧为标题与评分，避免长标题覆盖封面。卡间距 10px，每行高度按可用宽度控制在 112–142px，再适应文字缩放。点击任意卡进入对应真实条目的详情，不插入演示数据。其他频道保留现有精选卡。

四张卡从已分类的推荐池中按顺序分批选择，每批 ID 不重复。底部“换一批”使用带刷新图标与文字的轻描边胶囊按钮，只轮换本地推荐候选，不重新发起网络请求；候选不足四张时按实际数量展示，只有四张以内时禁用换批。换批使用短淡入淡出，系统关闭动画时直接切换；PC 图片沿用轻微放大且无悬浮背景色。

主分类与动漫子分类固定在内容滚动容器上方，因此正文滚动时仍可操作；子分类的高度、透明度、位移动画继续生效。顶部保留 `SafeArea` 和 8px 内容间距，不写死 Android 状态栏高度。底部用 `SafeArea` 消费系统手势/导航栏安全区，至少保留 8px，底部背景与导航一致，避免双重计算同一系统 inset。

推荐布局改动前副本：`.dart_tool/home-bento-{controller,view,shell}-baseline.dart`。这些副本包含本轮的数据分类修改，可单独回退新推荐布局。

本次样式重设计仅修改 `modern_home_view.dart` 与本文，保留数据算法、换批行为和安全区配置。此前一大两小样式副本：`.dart_tool/home-bento-redesign-baseline.dart`。

四卡版修改 `modern_home_view.dart` 与 `modern_home_controller.dart`，将推荐布局和每批数量统一为四张；不改分类算法。四卡版回退副本：`.dart_tool/home-four-cards-{view,controller}-baseline.dart`。
